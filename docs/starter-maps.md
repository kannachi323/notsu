# Included maps

The app ships three complete version 1 `.notsumap` archives in `public/maps/`.
Each contains its manifest, original PCM WAV recording and two Chart v2
difficulties. These are short introductory synth arrangements, not commercially
released songs or imported third-party recordings.

| Pack | Duration | BPM | Difficulties |
| --- | --- | --- | --- |
| Orbit Signal | 32 seconds | 120 | First light / Orbit |
| Violet Hours | 26.67 seconds | 144 | Pulse / Afterglow |
| First Contact | 10 seconds | 192 | Introduction / Lift off |

Music is generated by the project's deterministic synthesizer in
`scripts/generate-starter-packs.mjs`: kick, hi-hat, bass, pad and melodic note cues.
The existing original practice choreography supplies the note arrangements, with
reduced-density first difficulties. Artist credit is `notsu sound lab`; mapper is
`notsu`. No external samples, songs, official logos or third-party covers are used.
Human musical/readability playtesting remains part of the full release gate.

Regenerate explicitly with `node scripts/generate-starter-packs.mjs` from the
repository root. It uses the installed Vite loader and the same pack writer and
validator used by the editor. Commit both the archives and the generated
`src/features/maps/data/starterCatalog.json`; changing audio/chart content creates
new revision identities, so avoid gratuitous regeneration of released content.
Builds and tests never regenerate the music.

Included maps merge with the local library by revision. Saving a favorite retains
its local metadata without creating a second entry. Import/export follows the
normal package contract: another player gets the recording and all difficulties
together. The starter integrity tests read the committed archives, verify their
catalog identities, PCM duration/energy/headroom and difficulty metadata, and run
each difficulty through the real scoring engine's Autoplay.

The shared interface background `src/features/home/assets/orbital-night.png` was
created with the built-in image-generation tool from the adjacent saved prompt.
It is application artwork; v1 map packages do not yet support separate cover art.
The desktop bundle includes its media. Browser access still needs the application
to load; this work does not add a service worker or promise cold-start offline web
installation.
